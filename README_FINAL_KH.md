# Travel App — ការណែនាំ (ខ្មែរ)

## រូបភាពដែលបានភ្ជាប់
- `home_screen.dart`: បន្ថែមផ្នែក Popular restaurants ដោយប្រើរូបភាព `resturant.jpg` និង `resturant_1.jpg` ដល់ `resturant_4.jpg`។
- `hotel_search_screen.dart`: បន្ថែមទិន្នន័យ Demo សម្រាប់សណ្ឋាគារ និងរីសតដោយប្រើរូបភាពដែលមានក្នុង `assets/images/`។
- `places_screen.dart`: បន្ថែមកន្លែងទេសចរណ៍ និងប្រភេទ Nature។
- `pubspec.yaml` បានកំណត់ `assets/images/` រួចហើយ ដូច្នេះមិនចាំបាច់ចុះបញ្ជីរូបភាពមួយៗទេ។

## របៀបរត់ Project
នៅក្នុង Terminal របស់ Flutter project រត់៖

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## ចំណាំ
ឈ្មោះឯកសាររូបភាពត្រូវតែដូចគ្នាពិតៗនឹង path ក្នុង Dart code។ ទិន្នន័យសណ្ឋាគារ និងកន្លែងទេសចរណ៍ក្នុងកំណែនេះជាទិន្នន័យ Demo មិនមែនតម្លៃ ឬការកក់ដែលបានផ្ទៀងផ្ទាត់ជាក់ស្តែងទេ។
